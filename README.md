# Web Technology Laboratory - JavaScript Practical Record

A modern, responsive, and aesthetic static web application containing **10 complete HTML & JavaScript laboratory experiments** for practical records.

Each experiment includes the Aim, standalone source code, live interactive preview sandbox, sample expected output, and instant one-click copy and download functionality.

## ✨ Features

- **One-Click Program Copy**: Instant clipboard copy with animated visual confirmation and toast alerts.
- **Copy Title & Aim**: Quickly copy the title and aim format for writing lab records.
- **Live Interactive Sandbox**: Run and test each JavaScript program directly within an embedded environment.
- **Download Standalone `.html`**: Download any individual experiment file with one click.
- **Search & Category Filters**: Search experiments by title, keywords, or filter by topic.
- **Dark & Light Mode**: Toggle between sleek dark mode and clean light theme.
- **Compiled Record Modal**: View and copy all 10 programs consolidated into a single document.
- **Keyboard Shortcuts**: Navigate with arrow keys (`←` / `→`), copy with `C`, or press numbers `1`–`9` and `0` to jump.

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/yuvanaveen7845-ui/webcode.git
   ```
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, serve with any local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000/`.
